# Mr. G — The Nuanu Cruise (prototype)

Static site, no build step. Run locally:

    python -m http.server 5178 --directory site

Sections: hero (Mr. G) → parade of headliners (scroll) → "the machine" (concept loop, turn the crank) → the bill (offer terms) → gate / CTA.

- `talents.js` — headliners shown in the cars (generated from `talent_gallery/talents.json`).
- `anchors.js` — head attachment points, generated by `tools/anchors.py`.
- `assets/` — WebP art exported by `tools/export_assets.py` (from `recovered_mrg_assets/png`), heads by `tools/make_heads.py`.
- `roster.html` — copy of the full 104-creator roster page.
- `tools/shoot.py` — headless screenshots for visual checks.
